Új terméket a `products.create()` hoz létre. A nettó és a bruttó egységár közül pontosan egyet adhatsz meg, a másikat a Billingo számolja ki. A tárca típusa ezt fordításkor kikényszeríti.

```ts
const termek = await tarca.products.create(adatok)
```
