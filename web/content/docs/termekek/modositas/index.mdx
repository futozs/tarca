---
title: Módosítás
description: Termék módosítása a products.update() metódussal. A PUT teljes csere pontosan egy árral, ezért a lekért termékből az egyik árat el kell hagyni.
official: https://app.swaggerhub.com/apis/Billingo/Billingo/3.0.14#/Product/UpdateProduct
---

A `products.update()` PUT kéréssel a teljes terméket cseréli, és pontosan egy árat fogad el. A lekért termékben mindkét ár benne van, ezért visszaküldés előtt az egyiket hagyd el.

```ts
const termek = await tarca.products.update(id, adatok)
```
