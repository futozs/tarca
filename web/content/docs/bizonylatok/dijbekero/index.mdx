A díjbekérő (proforma) fizetési felszólítás, nem számla: nem megy a NAV-hoz, és nem sztornózható. Amikor a vevő fizet, a díjbekérőből számla lesz.

<Operation id="CreateDocumentFromProforma" methods={['documents.createFromProforma']} />

<Operation id="ArchiveDocument" methods={['documents.archive']} />

```ts
const dijbekero = await tarca.documents.create({ type: 'proforma', partner, items })
const szamla = await tarca.documents.createFromProforma(dijbekero.id ?? 0)
await tarca.documents.archive(dijbekero.id ?? 0)
```

A díjbekérőt a [Kiállítás](/docs/bizonylatok/kiallitas) `create()` metódusa hozza létre `type: 'proforma'` értékkel. A sorszáma külön számozást kap: `000001`.

<Callout type="warning" title="A díjbekérőből készült számla már fizetett">
  A `createFromProforma()` számlája `paymentStatus: 'paid'` állapottal jön létre. Ha utána
  befizetést is rögzítesz rá, kétszer számolod a pénzt.
</Callout>
