A `documents.list()` egy oldalt ad vissza, a `documents.all()` végigmegy az összes oldalon. Mindkettő a `GET /documents` szűrőit ismeri.

<Operation id="ListDocument" methods={['documents.list', 'documents.all']} />

```ts
const oldal = await tarca.documents.list({ paymentStatus: 'outstanding', perPage: 50 })
```
