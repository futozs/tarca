A piszkozat sorszám nélküli bizonylat: nem megy a NAV-hoz, és törölhető. Akkor hasznos, ha a számlát valaki még átnézi a Billingo felületén, vagy ha a végleges adatok később érkeznek.

<Operation id="CreateDocumentFromDraft" methods={['documents.finalizeDraft']} />

<Operation id="DeleteDocument" methods={['documents.deleteDraft']} />

```ts
const piszkozat = await tarca.documents.create({ type: 'draft', partner, items })
const szamla = await tarca.documents.finalizeDraft(piszkozat.id ?? 0, { partner, items })
```

A piszkozatot a [Kiállítás](/docs/bizonylatok/kiallitas) `create()` metódusa hozza létre `type: 'draft'` értékkel. A [Másolás](/docs/bizonylatok/masolas) is piszkozatot ad.
