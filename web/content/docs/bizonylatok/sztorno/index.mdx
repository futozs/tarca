Kiállított számlát nem lehet törölni, csak sztornózni: a Billingo egy sztornó bizonylatot állít ki, amely az eredeti összegeit ellentétes előjellel tartalmazza, és éles profilon ezt is beküldi a NAV-nak.

<Operation id="CancelDocument" methods={['documents.cancel']} />

```ts
const sztorno = await tarca.documents.cancel(szamla.id ?? 0, { reason: 'A vevő elállt a vásárlástól.' })
```

<Callout type="warning" title="Módosító számla után nincs sztornó">
  Ha egy számlához már készült módosító számla, a Billingo sem az eredetit, sem a módosítót nem
  engedi sztornózni: 400 `Cannot cancel the document` hibát ad. Ilyenkor egy újabb [módosító
  számlával](/docs/bizonylatok/modosito) helyesbíts. Díjbekérőt és piszkozatot sem lehet
  sztornózni: a díjbekérőt archiváld, a piszkozatot töröld.
</Callout>

Nyugta sztornója ugyanez a metódus, a különbségeket a [Nyugták: Sztornó](/docs/nyugtak/sztorno) oldal írja le.
