A `currencies.rate()` megmondja, mennyit ér egy pénznem egysége a másikban egy adott napon a Billingo szerint. Akkor van rá szükséged, ha devizás bizonylatot állítasz ki vagy devizás költséget rögzítesz, és a forintos értéket a Billingo árfolyamával számolnád.

<Operation id="GetConversionRate" methods={['currencies.rate']} />

```ts
const { rate } = await tarca.currencies.rate({ from: 'EUR', to: 'HUF', date: '2026-11-13' })
```

<Callout type="info" title="Devizás számlához nem kötelező">
  Devizás számlánál a `conversionRate` mezőt te adod meg, bármilyen forrásból. Ha a Billingo
  árfolyamát tennéd rá, előbb kérd le ezzel a hívással a teljesítés napjára. A szabályok a
  [Deviza](/docs/bizonylatok/kiallitas/szabalyok/deviza) oldalon vannak, a devizás költség példája a
  [Költség létrehozása](/docs/koltsegek/letrehozas/keres#devizás-költség) oldalon.
</Callout>
