A bankszámla az a számlaszám, amelyet a Billingo átutalásos számlán a fizetési adatok közé ír. A tárcában a `tarca.bankAccounts` kezeli, ez a legegyszerűbb erőforrás: öt művelet, hét mező.

```ts
const bankszamla = await tarca.bankAccounts.create({ name: 'Fő számla', accountNumber: '11111111-22222222-33333333', currency: 'HUF' })
```

Számla kiállításakor a `bankAccountId` mezővel választasz bankszámlát, vagy a kliens `defaults.bankAccountId` beállításával egyszer, minden bizonylatra. Lásd [Alapértékek](/docs/alapok/alapertekek).

<Callout type="info" title="Friss teszt profilon nincs bankszámla">
  Egy új fejlesztői teszt profilon a bankszámlák listája üres. Bankszámla nélkül a számla
  kiállítható, a bizonylat szervezeti adataiban ilyenkor a bankszámla azonosítója `null`. A
  `npx tarcajs doctor` figyelmeztet, ha a profilnak nincs bankszámlája.
</Callout>
