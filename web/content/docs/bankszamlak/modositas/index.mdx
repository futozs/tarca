---
title: Módosítás
description: Bankszámla módosítása a bankAccounts.update() metódussal. A PUT teljes csere, ezért a teljes bankszámlát kell elküldeni, a kihagyott IBAN és SWIFT kiürül.
official: https://app.swaggerhub.com/apis/Billingo/Billingo/3.0.14#/BankAccount/UpdateBankAccount
---

A `bankAccounts.update()` PUT kéréssel a teljes bankszámlát cseréli. A kihagyott IBAN és SWIFT kiürül, ezért előbb kérd le a bankszámlát, és az egészet küldd vissza.

```ts
const bankszamla = await tarca.bankAccounts.update(id, adatok)
```
