A `partners.guess()` a Billingo `POST /partners/guess` végpontját hívja, amely csak a 3.0.15-ös specben szerepel. Pontos névegyezésnél a meglévő partnert adja vissza, minden más esetben újat hoz létre. A tárca saját partnerkeresése, a [`findOrCreate()`](/docs/partnerek/kereses-vagy-letrehozas), ezért nem erre épül.

```ts
const partner = await tarca.partners.guess(vevo)
```
