A `tarcajs/testing` egy memóriában futó Billingót ad egy `fetch` függvény mögött. A valódi kliens fut fölötte, így a saját kódod tesztje ugyanazt a validációt, sorszámozást, kerekítést és ugyanazokat a hibákat látja, mint élesben, csak kérés nem megy ki. Ezen fut a weboldal [sandboxa](/sandbox) is. A modul futtatókörnyezet-független és függőség nélküli, a `tarcajs` gyökér nem importálja.

```ts twoslash
import { createMockTarca } from 'tarcajs/testing'

const tarca = createMockTarca()

const { document } = await tarca.documents.createOnce({
  vendorId: 'ORDER-1001',
  partner: {
    name: 'Vevő Kft.',
    address: { postCode: '1111', city: 'Budapest', address: 'Fő utca 1.' },
  },
  items: [{ name: 'Webfejlesztés', quantity: 10, unit: 'óra', netUnitPrice: 15_000, vat: 27 }],
})

console.log(document.invoiceNumber, document.grossTotal, tarca.billingo.count('CreateDocument'))
```

A számla `2026-1` sorszámot kap, a bruttó végösszeg `190500`, a hamis Billingo egy kiállító kérést kapott.

## Melyiket mikor?

| | `createMockTarca()` | `createFakeBillingoFetch()` |
| --- | --- | --- |
| Mit ad? | Kész `Tarca` klienst a hamis Billingón | Egy `fetch` függvényt, amelyet te adsz a saját `createTarca()` hívásodnak |
| Mikor jó? | A saját függvényed kapja a klienst paraméterként | A kódod maga hozza létre a klienst, vagy a beállításait (`timeoutMs`, `hooks`) is tesztelnéd |
| Hívásnapló | `calls`: metódusnév és argumentumok | nincs |
| Kérésnapló | `billingo.requests` | `requests` |
| Hiba szimulálása | `failNext(metódus)` a kliens szintjén, és `billingo.fail()` | `fail()` a drót szintjén |

Mindkettő a [hamis Billingón](/docs/tesztek/hamis-billingo) fut, ugyanazzal az állapottal és ugyanazokkal a [hibákkal](/docs/tesztek/hibak-szimulalasa).

<Callout type="info" title="A tesztek ne hívják az éles API-t">
  A hamis Billingónak nem kell API kulcs, és nem megy ki tőle kérés. Ha a valódi Billingón is
  kipróbálnád a kódodat, arra a fejlesztői teszt profil való, külön kulccsal. Lásd [Telepítés](/docs/alapok/telepites).
</Callout>
