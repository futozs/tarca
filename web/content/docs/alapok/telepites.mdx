## Telepítés

```npm
npm install tarcajs
```

A csomag Node.js 22-től, Bun, Deno és Cloudflare Workers alatt fut, ESM és CommonJS buildként. Futásidejű függősége nincs: a natív `fetch`-et használja. A típusok a csomagban vannak, külön `@types` csomag nem kell.

## API kulcs

A kulcsot a Billingo felületén hozod létre: Beállítások → API kulcsok → Új API kulcs, a **V3** változattal. Olvasó és író jogú kulcs kell, ha számlát is kiállítasz. A részletek: [Hitelesítés](/docs/alapok/hitelesites).

A tárca a kulcsot a `BILLINGO_API_KEY` környezeti változóból olvassa:

```dotenv title=".env"
BILLINGO_API_KEY=a-te-api-kulcsod
```

```ts twoslash title="lib/tarca.ts"
import { createTarca } from 'tarcajs'

export const tarca = createTarca()
```

Ha sehol nincs kulcs, a `createTarca()` azonnal `configuration` kategóriájú `BillingoError`-t dob, nem az első kérésnél. Egy folyamatban elég egyszer létrehozni a klienst, és mindenhol azt használni.

<Callout type="tip" title="Fejlesztéshez a teszt profil">
  A Billingo ingyenes fejlesztői teszt profilján nincs NAV kapcsolat, a bizonylatokon „TESZT”
  felirat van, és előfizetés sem kell. Éles profilon a kiállított számlát a Billingo azonnal
  beküldi a NAV-nak, és utána csak sztornózni lehet. Lásd [Teszt profil](/docs/alapok/teszt-profil).
</Callout>

## Az első számla

<Example slug="szamla" />

Egy hívásból négy kérés lesz: a tárca lekéri az első számlatömböt, név szerint megkeresi a partnert, és mivel még nincs ilyen, létrehozza, végül kiállítja a számlát. A teljesítés napját, a 8 napos határidőt, az átutalásos fizetési módot és az áfakódot is ő tölti ki. A sorszámot és az összegeket a Billingo adja.

Webshopból és webhookból ugyanezt a `createOnce()`-szal tedd, a rendelésed azonosítójával: [Pontosan egyszer](/docs/alapok/pontosan-egyszer).

## A kulcs ellenőrzése

```ts twoslash
import { createTarca } from 'tarcajs'

const tarca = createTarca()

if (!(await tarca.verifyCredentials())) {
  throw new Error('A Billingo nem fogadta el az API kulcsot.')
}
```

A `verifyCredentials()` egy `GET /organization` kérést küld. `false` az eredmény, ha a Billingo elutasítja a kulcsot (401); minden más hibát (hálózat, előfizetés) továbbdob.

Parancssorból ugyanezt az `npx tarcajs doctor` végzi el: ellenőrzi a kulcsot, a profilt, a NAV-kapcsolatot és a számlatömböket. Részletek: [Parancssor](/docs/kiegeszitok/parancssor).

## Cloudflare Workers és Deno

Workers alatt a kulcs a kérés `env` paraméterében érkezik, ezért az `apiKey` opcióval add át:

```ts twoslash title="src/index.ts"
import { createTarca } from 'tarcajs'

export default {
  async fetch(_request: Request, env: { BILLINGO_API_KEY: string }) {
    const tarca = createTarca({ apiKey: env.BILLINGO_API_KEY })
    return Response.json(await tarca.utils.serverTime())
  },
}
```

Denóban az npm csomagot az `npm:` előtaggal importálod (`import { createTarca } from 'npm:tarcajs'`). A kulcsot add át az `apiKey` opcióval, például `Deno.env.get('BILLINGO_API_KEY')` értékével. A tárca a `process.env`-et csak akkor olvassa, ha a futtatókörnyezetben létezik. Több futtatókörnyezetről: [Serverless és edge](/docs/kiegeszitok/serverless-es-edge).
