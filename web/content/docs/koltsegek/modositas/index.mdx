official: https://app.swaggerhub.com/apis/Billingo/Billingo/3.0.14#/Spending/SpendingUpdate

A `spendings.update()` PUT kéréssel a teljes költséget cseréli, ugyanazokkal a kötelező mezőkkel, mint a létrehozás. Élőben a kihagyott `comment` üres szöveg lett, ezért a megtartandó mezőket is küldd vissza.

```ts
const koltseg = await tarca.spendings.update(id, { ...adatok, paidAt: new Date() })
```
