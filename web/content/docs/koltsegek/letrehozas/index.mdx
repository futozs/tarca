Bejövő számlát a `spendings.create()` rögzít költségként. A `conversionRate`, az `invoiceNumber`, az `invoiceDate` és a `dueDate` a specben opcionális, de a Billingo élőben nélkülük 422-t ad, ezért a tárca típusában kötelezők.

```ts
const koltseg = await tarca.spendings.create(adatok)
```
