official: https://app.swaggerhub.com/apis/Billingo/Billingo/3.0.14#/Spending/SpendingList

A `spendings.list()` egy oldalt ad vissza, a `spendings.all()` minden oldalt bejár ugyanazokkal a szűrőkkel. A `q` keresés élőben a pontos számlaszámra sem talált, számlaszámra máshogy keress.

```ts
const lejart = await tarca.spendings.list({ paymentStatus: 'expired' })
```
