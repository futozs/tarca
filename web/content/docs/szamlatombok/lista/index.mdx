A `documentBlocks.list()` egy oldalt ad vissza, a `documentBlocks.all()` minden oldalt bejár. Típus szerint is szűrhetsz, például csak a nyugtatömbökre.

```ts
const nyugtaTombok = await tarca.documentBlocks.list({ type: 'receipt' })
```
