description: Számlatömb módosítása a documentBlocks.update() metódussal. Nem dokumentált, élőben ellenőrzött PUT teljes cserével, a kiürülő mezők és a null e-mailre adott 422.
official: https://app.swaggerhub.com/apis/Billingo/Billingo/3.0.15#/DocumentBlock/ListDocumentBlock
---

A `PUT /document-blocks/{id}` egyik Billingo specben sincs benne, a viselkedését élőben mértük ki. A `documentBlocks.update()` a teljes tömböt cseréli: a `name`, a `prefix` és a `type` kötelező. A lekért tömböt változtatás nélkül visszaküldheted, mert a tárca kihagyja a törzsből a csak olvasható és a `null` értékű mezőket.

```ts
const tomb = await tarca.documentBlocks.update(id, { ...regi, name: 'Webshop 2027' })
```
