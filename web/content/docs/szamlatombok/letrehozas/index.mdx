Új számlatömböt a `documentBlocks.create()` hoz létre. A végpont csak a 3.0.15-ös specben szerepel. Az előtag és a típus kötelező. A névben csak betű, szám és szóköz lehet, ezt a tárca kérés előtt ellenőrzi.

```ts
const tomb = await tarca.documentBlocks.create(adatok)
```
