A nyugta piszkozat sorszám nélküli nyugta. Akkor hasznos, ha a pénztárban a kosár már összeállt, de a fizetés még nem zárult le. Véglegesítéskor a Billingo sorszámot ad neki, és fizetett nyugta lesz belőle.

<Operation id="CreateReceiptFromDraft" methods={['receipts.finalizeDraft']} />

```ts
const piszkozat = await tarca.receipts.create({ type: 'draft', items })
const nyugta = await tarca.receipts.finalizeDraft(piszkozat.id ?? 0, { items, paymentMethod: 'bankcard' })
```

A piszkozatot a [Kiállítás](/docs/nyugtak/kiallitas) `create()` metódusa hozza létre `type: 'draft'` értékkel. Törölni a számlákéval közös `documents.deleteDraft()` tudja, lásd [Bizonylatok: Piszkozat](/docs/bizonylatok/piszkozat).
