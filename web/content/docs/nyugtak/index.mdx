A nyugta a Billingóban külön bizonylattípus: a `receipt` típusú nyugtatömbbe kerül, az árai bruttók, és kiállításkor már fizetett. A tárcában a `tarca.receipts` állítja ki, a lekérés, a sztornó és a PDF pedig ugyanaz, mint a számláknál (`tarca.documents`).

```ts twoslash
import { createTarca } from 'tarcajs'

const tarca = createTarca()

const { document, created } = await tarca.receipts.createOnce({
  vendorId: 'POS-1001',
  items: [
    { name: 'Kávé', quantity: 2, grossUnitPrice: 600, vat: 27 },
    { name: 'Croissant', grossUnitPrice: 750, vat: 5 },
  ],
  paymentMethod: 'bankcard',
})

console.log(document.invoiceNumber, document.grossTotal, created)
```

## Miben más, mint a számla?

| | Nyugta | Számla |
| --- | --- | --- |
| Metódus | `receipts.create()`, `receipts.createOnce()` | `documents.create()`, `documents.createOnce()` |
| Tömb | az első `receipt` típusú tömb vagy `defaults.receiptBlockId` | az első `invoice` típusú tömb vagy `defaults.blockId` |
| Sorszám | `NYT-2026-1` | `2026-1` |
| Ár | csak bruttó (`grossUnitPrice`) | nettó vagy bruttó |
| Áfa | `5`, `18`, `27`, `'none'`, `'AAM'`, `'TAM'` | a teljes `Billingo.Vat` lista |
| Partner | nem kötelező | kötelező |
| Fizetési mód alapértéke | `defaults.paymentMethod`, különben `'cash'` | `defaults.paymentMethod`, különben `'wire_transfer'` |
| Fizetési állapot | mindig `paid` | `outstanding`, amíg nem rögzítesz befizetést |
| Határidő | a kiállítás napja | `dueDate` vagy `dueInDays` |

A `vendorId` közös térben van: egy `POS-1001` nyugta után nem állíthatsz ki `POS-1001` számlát.

## Nyugta vagy számla?

Magánszemélynek, pénztárnál vagy webshopban jellemzően nyugta jár, cégnek vagy kérésre számla. Fizetési webhookból a `tarcajs/payments` dönt helyetted a vevő adatai és az összeg alapján: [Nyugta vagy számla](/docs/fizetesek/nyugta-vagy-szamla).

<Callout type="info" title="Nyugta-adatszolgáltatás">
  2026. szeptember 1-jétől a nyugták adatai is a NAV-hoz kerülnek. A beküldést a Billingo végzi,
  új API végpont nincs hozzá: a nyugta `kobakReceiptStatus` mezője mutatja az állapotát (`pending`,
  `success`, `error_no_access`, `error_permanent`). A teszt profilon a nyugta `pending` marad.
</Callout>
